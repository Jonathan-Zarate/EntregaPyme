# Bitacora - inicio del proyecto

## Solicitud

Construir desde cero un MVP web responsive de delivery B2B en Peru con empresas, motorizados y administradores, sin mapas, GPS, pagos automaticos ni aplicacion movil.

## Decisiones propuestas por el agente

- Nombre provisional `EntregaPyme` y repositorio separado en `E:\entrega-pyme`.
- Monolito modular para reducir costo operativo.
- Neon y Vercel como infraestructura administrada.
- Better Auth y sesiones persistidas para evitar roles congelados en tokens.
- Saldo disponible y reservado, respaldado por libro mayor.
- Precio empresa y pago motorizado separados.
- Aceptacion de pedidos atomica.

## Revision humana

Jonathan aprobo continuar con la estructura propuesta.

## Ajustes realizados

- npm no admite mayusculas en nombres de paquete; se normalizo la carpeta a `entrega-pyme` sin cambiar el nombre del producto.
- El enlace de `node_modules` en `E:` presento lentitud anormal; se evaluara un metodo de importacion local alternativo.

- migracion aplicada en una base de datos de prueba
